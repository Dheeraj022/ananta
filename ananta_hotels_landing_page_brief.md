# Ananta Hotels -- Landing Page & Website Development Brief

## 1. Project Overview

Build a premium, responsive, lead-generation website for an independent
travel partner showcasing four Ananta hotel properties in Rajasthan.

The website must feel visually connected to the Ananta Hotels brand and
its hospitality style, while clearly communicating that this is an
**independent travel partner website**, not the official Ananta Hotels
website.

**Primary objective:** Generate qualified enquiries for stays at the
four featured properties.

**Current scope:** Property discovery, property information,
accommodation browsing and enquiry submission only.

**Do not build in the current phase:** Direct booking, live room
availability, payment gateway, booking confirmation, invoice generation
or hotel operations software.

Keep the architecture clean enough that booking and business-operation
features could be added in a future phase without rebuilding the entire
site.

## 4. Visual Direction and Brand Identity

The supplied Ananta Hotels homepage screenshot is the visual reference
for the colour mood, typography hierarchy, image-led layout and premium
hospitality feel.

The website should look elegant, calm, nature-inspired and
editorial---not like a generic travel template or an AI-generated
landing page.

### Colour palette

Use these as initial design tokens. They are visual approximations from
the supplied screenshot, not verified official brand colour codes.

  -----------------------------------------------------------------------
  Token                   Suggested colour        Usage
  ----------------------- ----------------------- -----------------------
  Primary background      `#FFFFFF`               Main page background

  Forest green            `#286B4D`               Headings, links,
                                                  buttons and brand
                                                  accents

  Earthy brown            `#70452F`               Feature bands and
                                                  selected content
                                                  sections

  Warm beige              `#E9DDC5`               Soft section
                                                  backgrounds and cards

  Deep charcoal green     `#17251F`               Dark image overlays and
                                                  contrast sections

  Muted gold              `#C6A66B`               Small decorative
                                                  highlights only
  -----------------------------------------------------------------------

### Colour rules

-   White should remain the primary background.
-   Forest green should be the main brand accent.
-   Use beige and earthy brown in alternating sections to create warmth
    and depth.
-   Use deep charcoal green for occasional dark sections, especially
    where large photography needs contrast.
-   Use muted gold sparingly.
-   Avoid neon green, bright gradients, oversaturated colours and
    excessive shadows.
-   Maintain accessible text contrast.

### Typography

Match the elegant, understated hospitality typography seen in the
supplied reference screenshot.

Recommended font pairing:

-   **Headings:** Cormorant Garamond or Playfair Display.
-   **Body copy and UI:** Lato or Montserrat.
-   **Decorative italic text:** Cormorant Garamond Italic.

Typography treatment:

-   Main headings: refined serif, light or regular weight, often
    uppercase, with generous letter spacing.
-   Section headings: classic serif; use italic styling selectively.
-   Body text: clean sans-serif, readable size, relaxed line height and
    restrained line length.
-   Navigation: small, neat uppercase or subtly letter-spaced
    sans-serif.
-   Buttons: clean sans-serif, concise labels and understated styling.
-   Avoid heavy bold typography throughout the page.
-   Do not use script fonts for long text or important navigation.

These are suggested visual matches, not a claim that they are the exact
fonts used by Ananta.

## 5. Home Page Layout

Create a polished, image-led home page with the following sections in
this order.

### 5.1 Header

-   Brand/logo area on the left.
-   Main navigation on desktop.
-   Clear enquiry/contact action.
-   Sticky header may be used, but keep it slim and unobtrusive.
-   Use a white or translucent treatment depending on the hero image
    contrast.
-   Do not create a logo that falsely suggests the website is the
    official Ananta Hotels website. Use only client-approved branding.

### 5.2 Hero section

-   Large, high-quality resort/property photograph or a carefully
    selected image carousel.
-   Elegant headline introducing the collection of featured stays.
-   Short supporting copy focused on discovering properties and sending
    an enquiry.
-   Primary CTA: **Explore Properties**
-   Secondary CTA: **Send an Enquiry**
-   Do not use "Book Now" or wording that suggests an instant confirmed
    booking.
-   Add a compact enquiry/search strip only if it is clearly an enquiry
    form, not a live availability checker.

### 5.3 Introduction section

-   Short introduction to the independent travel partner service.
-   Explain that the website helps visitors explore the featured
    properties and submit stay enquiries.
-   Include a visible independent-partner disclosure.

### 5.4 Featured properties

Show all four properties in a premium responsive grid.

Each property card should include:

-   Property image
-   Correct property name
-   City/location
-   Brief factual description
-   CTA: **Explore Property**

Clicking a card or CTA must open that property's dedicated page.

Use large photography, consistent image ratios, restrained borders and
elegant typography. Avoid overcrowded cards.

### 5.5 Why explore with us

Create a concise trust section explaining the enquiry assistance offered
by the independent travel partner. Do not make unverified claims such as
guaranteed best prices, exclusive rates, official status or guaranteed
availability.

### 5.6 Experience / highlights section

Use factual, property-supported highlights such as location, setting,
accommodation or facilities. Do not add generic claims that cannot be
substantiated.

### 5.7 Enquiry CTA

Add a clear enquiry section with a short explanation:

"Share your preferred property and stay details. Our team will get in
touch to assist with your enquiry."

CTA: **Send Your Enquiry**

### 5.8 Footer

Include:

-   Navigation links
-   Links to all four properties
-   Contact details supplied by the client
-   About Us
-   Privacy Policy
-   Disclaimer
-   Terms & Conditions
-   Independent travel partner disclosure
-   Copyright notice

Do not invent phone numbers, email addresses, office addresses or social
media links. Use placeholders until the client supplies verified
details.

## 7. Accommodation Section -- Important UI Requirement

Use the supplied **Aamby Valley City accommodation page** as the
interaction and layout reference.

The accommodation section must be compact and easy to browse. Do not
create a separate long page for every room unless requested later.

### Accommodation accordion

-   Display each accommodation/room type as an accordion item.
-   Keep the initial view compact, showing room name and a small visual
    cue.
-   On click/tap, expand the selected accommodation to reveal its
    details.
-   Include a room-specific image carousel/gallery inside the expanded
    panel.
-   Include the verified room description and available factual details.
-   Add an **Enquire About This Room** CTA.
-   The accordion must work with mouse, keyboard and touch.
-   Use a clear open/close state and smooth, subtle animation.
-   On mobile, ensure the carousel and accordion are easy to operate.
-   Do not use a dropdown that hides important room information in an
    unclear way.

### Room enquiry behaviour

When a visitor clicks **Enquire About This Room**:

-   Open the enquiry form in a modal, side panel or clearly visible
    section.
-   Automatically prefill the selected property.
-   Automatically prefill the selected accommodation/room name.
-   Preserve the selected room if the visitor submits the form.
-   Provide a clear close/back action if using a modal.

### Room content

Use the actual accommodation names, descriptions, facilities and images
available for that property. If information is unavailable, do not
invent it. Mark missing content for client review.

## 8. Enquiry Form and Lead Generation

The website is an enquiry-generation platform only.

### Suggested form fields

Required:

-   Full Name
-   Email Address
-   Phone Number (with country code)
-   Preferred Property
-   Check-in Date
-   Check-out Date
-   Number of Adults
-   Number of Children (optional)
-   Selected Accommodation / Room (optional, auto-filled when launched
    from a room)
-   Message / Special Requirements (optional)

Add consent checkbox for the privacy policy where legally appropriate.

### Form behaviour

-   Validate required fields.
-   Validate email and phone format sensibly.
-   Check that check-out is later than check-in.
-   Show clear inline error messages.
-   Show a loading state while submitting.
-   Prevent accidental duplicate submissions.
-   Show a thank-you message/page after successful submission.
-   Store or deliver leads through a backend/email/CRM integration
    approved by the client.
-   Do not claim that a lead has been delivered unless the integration
    confirms success.
-   Do not display live availability or promise that the requested room
    is available.

### Enquiry confirmation wording

Use wording such as:

"Thank you for your enquiry. Your request has been submitted
successfully. Our team will contact you regarding the details."

Add this notice near the form submit button:

"Submitting an enquiry does not confirm a booking or guarantee room
availability. All requests are subject to confirmation through the
relevant property or booking channel."

Never label the form submission as a confirmed reservation.

## 9. Independent Travel Partner Disclosure

This is a critical requirement and must be implemented consistently.

The website must clearly identify itself as an independent travel
partner. It must not mislead visitors into believing it is the official
Ananta Hotels website or an official hotel booking engine.

Suggested wording, subject to client/legal approval:

" We are an independent travel partner providing property information
and assisting visitors with stay enquiries. We are not the official
website of Ananta Hotels. Property names, descriptions and images are
used for identification and informational purposes, subject to
applicable permissions. Enquiry submission does not confirm a booking or
guarantee availability."

### Where to display the disclosure

-   Footer on every page.
-   About Us page.
-   Property pages, near the enquiry section.
-   Enquiry form, before submission.
-   Disclaimer page.

Use the exact approved legal wording supplied by the client if
available. Do not claim "authorised partner", "official partner" or
"representative" without documented authorisation.

## 13. UX, Responsiveness and Accessibility

-   Fully responsive across mobile, tablet, laptop and large desktop.
-   Design mobile-first.
-   Use consistent spacing, grid widths and typography.
-   Ensure readable font sizes and comfortable line lengths.
-   Use semantic HTML and accessible heading order.
-   Provide visible keyboard focus states.
-   Ensure accordions and carousels are keyboard accessible.
-   Add descriptive alt text to meaningful images.
-   Respect reduced-motion preferences.
-   Avoid excessive animation, parallax and auto-playing elements.
-   Optimise image sizes and use responsive image formats.
-   Maintain good colour contrast.

------------------------------------------------------------------------

## 19. Final Design and Development Direction

The finished website should combine:

1.  The Ananta Hotels reference website's nature-inspired colour palette
    and premium visual identity.
2.  Elegant serif headings with clean sans-serif body typography.
3.  Large, authentic property photography and calm editorial layouts.
4.  The Aamby Valley accommodation interaction pattern: compact
    accordion, room image carousel, room details and enquiry CTA.
5.  A clear independent travel partner identity on every relevant page.
6.  A simple, reliable lead-generation journey with no false booking or
    availability promises.

**Priority order:** Brand-consistent design → accurate property
information → excellent accommodation browsing → clear enquiry journey →
responsive performance → SEO and launch readiness.

Build the experience carefully. Do not add unrequested features or
invent missing content. Where a client decision, approved asset, contact
detail, legal wording or integration is missing, mark it clearly for
confirmation instead of guessing.
